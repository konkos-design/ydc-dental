# Публикация Yasnovsky Dental Clinic

Сейчас это демо: на всех страницах сохранён `noindex, nofollow`. Не отправляйте sitemap демо на индексацию. robots.txt не заменяет noindex.

Текущий базовый адрес: https://konkos-design.github.io/ydc-dental/

Перед запуском купленного сайта:
1. Замените базовый URL в canonical, og:url, og:image, JSON-LD, sitemap.xml и robots.txt на окончательный HTTPS-домен. Canonical каждой страницы указывает на неё саму. Исключите 404 из sitemap.
2. На домене клиента замените префикс /ydc-dental/ в ссылках 404.html на /. Если сайт размещён в подпапке, используйте её фактический префикс.
3. Только перед запуском уберите noindex с обычных страниц. На 404 оставьте noindex. Убедитесь, что сервер не добавляет X-Robots-Tag: noindex для всего сайта.
4. robots.txt действует только в корне домена: /robots.txt. Файл внутри репозитория GitHub Pages не управляет роботами на всём github.io-домене. Перенесите его в корень итогового хостинга и проверьте доступ Googlebot.
5. GitHub Pages автоматически использует 404.html. На другом хостинге настройте выдачу этого файла со статусом HTTP 404 для отсутствующих URL, включая вложенные. Не перенаправляйте все ошибки на главную и не возвращайте HTTP 200.
6. Подтвердите собственность домена в Google Search Console, отправьте актуальный sitemap и проверьте URL главной и внутренних страниц. Подтверждение доступа выполняется с данными владельца, фиктивные токены не нужны.
7. Проверьте все страницы, звонки, меню, фильтры, галереи, ползунки, клавиатуру, отключённый/сломанный JS и размеры 360/390/430/768/1024/1280/1920. Проверьте HTTP 200/404 и консоль именно на опубликованном хостинге.

Основной призыв — звонок. Форма записи не предусмотрена. Контакты, отзывы, цены и часы взяты из существующих файлов и требуют подтверждения владельцем перед коммерческим запуском.
